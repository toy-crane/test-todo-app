## Overview
Trello 스타일의 칸반 보드 Todo 앱. 3개 고정 칼럼(To Do, In Progress, Done)에서 카드를 드래그&드롭으로 이동하고, 카드의 CRUD·인라인 편집·서브태스크 관리, 검색·필터, 다크모드, localStorage 기반 데이터 영속화 및 JSON 내보내기/가져오기를 지원한다.

## 시나리오

### 1. 칸반 보드 초기 표시
[상황] 앱을 처음 열면
[동작] 3개 칼럼(To Do, In Progress, Done)이 표시되고, 저장된 카드가 없으면 빈 보드가 나타난다

성공 기준:
- [ ] 앱 로드 -> "To Do", "In Progress", "Done" 3개 칼럼 헤더가 표시된다
- [ ] 저장된 데이터 없음 -> 각 칼럼에 카드가 0개 표시된다

### 2. 카드 추가
[상황] 칼럼에서 카드 추가를 시작하면
[동작] 제목을 입력하고 추가하면 해당 칼럼에 새 카드가 생성된다

성공 기준:
- [ ] "To Do" 칼럼에서 제목 "우유 사기" 입력 후 추가 -> "To Do" 칼럼에 "우유 사기" 카드가 표시된다
- [ ] 제목 없이 추가 시도 -> 카드가 생성되지 않는다

### 3. 카드 편집 화면 열기
[상황] 기존 카드를 클릭하면
[동작] 카드 상세 편집 화면이 열리고, 제목·설명·우선순위·태그·마감일 필드가 표시된다

성공 기준:
- [ ] 카드 "우유 사기" 클릭 -> 편집 화면에서 제목, 설명, 우선순위, 태그, 마감일 필드가 표시된다

### 4. 카드 인라인 편집
[상황] 카드 편집 화면에서 필드를 수정하면
[동작] 저장 후 수정된 내용이 카드에 반영된다

성공 기준:
- [ ] 제목을 "두유 사기"로 변경 후 저장 -> 카드 제목이 "두유 사기"로 표시된다
- [ ] 우선순위를 "High"로 변경 후 저장 -> 카드에 "High" 우선순위가 표시된다

### 5. 카드 편집 취소
[상황] 카드 편집 화면에서 내용을 변경한 후
[동작] 저장하지 않고 편집 화면을 닫으면 원본 데이터가 유지된다

성공 기준:
- [ ] 제목을 "두유 사기"로 변경하고 저장하지 않고 닫기 -> 카드 제목이 "우유 사기"로 유지된다

### 6. 카드 삭제
[상황] 카드 삭제를 실행하면
[동작] 해당 카드가 칼럼에서 제거된다

성공 기준:
- [ ] "우유 사기" 카드 삭제 -> 해당 칼럼에서 "우유 사기" 카드가 사라진다

### 7. 카드 드래그&드롭 이동
[상황] 카드를 다른 칼럼으로 드래그하면
[동작] 카드가 원래 칼럼에서 사라지고 대상 칼럼에 추가된다

성공 기준:
- [ ] "To Do"의 "우유 사기" 카드를 "In Progress"로 드래그 -> "To Do"에서 사라지고 "In Progress"에 표시된다
- [ ] "In Progress"의 카드를 "Done"으로 드래그 -> "In Progress"에서 사라지고 "Done"에 표시된다

### 8. 서브태스크(체크리스트) 관리
[상황] 카드 편집 화면에서 서브태스크를 추가하면
[동작] 체크리스트 항목이 추가되고, 체크/해제로 완료 상태를 토글할 수 있다

성공 기준:
- [ ] 서브태스크 "계란도 사기" 추가 -> 체크리스트에 "계란도 사기" 항목이 표시된다
- [ ] "계란도 사기" 체크 -> 해당 항목이 완료 상태로 표시된다
- [ ] 서브태스크 2개 중 1개 완료 -> 카드에 "1/2" 진행률이 표시된다

### 9. 서브태스크 삭제
[상황] 카드 편집 화면에서 서브태스크가 있는 상태에서
[동작] 서브태스크를 삭제하면 체크리스트에서 제거되고 진행률이 업데이트된다

성공 기준:
- [ ] 서브태스크 2개 중 "계란도 사기" 삭제 -> 체크리스트에서 "계란도 사기"가 사라지고 진행률이 업데이트된다

### 10. 제목 검색
[상황] 검색창에 텍스트를 입력하면
[동작] 제목에 해당 텍스트를 포함하는 카드만 필터링되어 표시된다

성공 기준:
- [ ] 카드 "우유 사기", "회의록 작성" 존재 시 "우유" 검색 -> "우유 사기"만 표시된다
- [ ] 검색어 삭제 -> 모든 카드가 다시 표시된다

### 11. 우선순위·태그 필터
[상황] 필터 옵션에서 우선순위나 태그를 선택하면
[동작] 선택한 조건에 맞는 카드만 표시된다

성공 기준:
- [ ] 우선순위 "High" 필터 선택 -> "High" 우선순위 카드만 표시된다
- [ ] 태그 "업무" 필터 선택 -> "업무" 태그가 있는 카드만 표시된다

### 12. 필터 해제
[상황] 필터가 적용된 상태에서
[동작] 필터를 해제하면 모든 카드가 다시 표시된다

성공 기준:
- [ ] 우선순위 "High" 필터 해제 -> 모든 카드가 다시 표시된다

### 13. 다크모드 토글
[상황] 다크모드 토글 버튼을 클릭하면
[동작] 앱 전체가 다크/라이트 테마로 전환된다

성공 기준:
- [ ] 라이트 모드에서 토글 클릭 -> 다크 모드 스타일이 적용된다
- [ ] 다크 모드에서 토글 클릭 -> 라이트 모드로 복귀한다

### 14. 데이터 localStorage 저장 (추가)
[상황] 카드를 추가하면
[동작] 변경된 데이터가 자동으로 localStorage에 저장되고, 새로고침 후에도 유지된다

성공 기준:
- [ ] 카드 "우유 사기" 추가 후 새로고침 -> "우유 사기" 카드가 그대로 표시된다

### 15. 데이터 localStorage 저장 (이동)
[상황] 카드를 다른 칼럼으로 이동하면
[동작] 이동 후 데이터가 localStorage에 저장되고, 새로고침 후에도 유지된다

성공 기준:
- [ ] 카드를 "Done"으로 이동 후 새로고침 -> "Done" 칼럼에 카드가 표시된다

### 16. JSON 내보내기
[상황] 내보내기 버튼을 클릭하면
[동작] 현재 보드 데이터가 JSON 파일로 다운로드된다

성공 기준:
- [ ] 카드 2개 존재 시 내보내기 -> JSON 파일이 다운로드된다
- [ ] 내보낸 JSON에 카드 제목, 칼럼 정보, 서브태스크 등 모든 데이터가 포함된다

### 17. JSON 가져오기
[상황] JSON 파일을 가져오기하면
[동작] 기존 데이터를 전체 덮어쓰고 가져온 데이터로 보드가 표시된다

성공 기준:
- [ ] 유효한 JSON 파일 가져오기 -> 기존 데이터가 교체되고 가져온 카드들이 표시된다
- [ ] 잘못된 형식의 JSON 가져오기 -> 오류 메시지가 표시되고 기존 데이터가 유지된다

## 범위

### 포함
- 3칼럼 고정 칸반 보드 (To Do / In Progress / Done)
- 카드 CRUD (제목, 설명, 우선순위, 태그, 마감일, 서브태스크)
- 카드 드래그&드롭 칼럼 간 이동
- 인라인 편집 (카드 클릭 시 상세 편집)
- 서브태스크 체크리스트 (추가/삭제/완료토글/진행률)
- 제목 실시간 검색
- 우선순위·태그 다중 필터
- 다크모드 수동 토글
- localStorage 자동 저장
- JSON 내보내기/가져오기 (가져오기 시 전체 덮어쓰기)

### 제외
- 칼럼 추가/삭제/이름변경: 고정 3칼럼으로 충분하며 구현 복잡도를 줄이기 위해 제외
- 시스템 다크모드 자동 감지: 수동 토글로 충분하며 초기 버전 범위를 줄이기 위해 제외
- 멀티 유저/실시간 협업: 로컬 전용 앱으로 범위 한정
- 담당자/라벨/첨부파일: 기본 필드셋으로 충분하며 추후 확장 가능
- JSON 가져오기 시 병합: 전체 덮어쓰기 방식으로 단순화

## 전제 조건
- 브라우저 localStorage 사용 가능
- 모던 브라우저 (드래그&드롭 API 지원)
- React + shadcn/ui 기반 구현
